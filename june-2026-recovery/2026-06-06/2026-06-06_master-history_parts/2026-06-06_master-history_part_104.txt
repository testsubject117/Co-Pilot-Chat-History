The starting point was a fully functioning WinForms report screen that already loaded ledger/check/invoice data and identified imbalance cases. The file provided by the operator was **`FormLedgerDoesntBalance.vb`**, which contains the following major logic components:
- **`RunReportAsync()`** for asynchronous report generation
- **`ComputeRows(...)`** for building mismatch rows
- **`ApplyFilterAndBind()`** for filter application and sorting
- **`dgv_RowPrePaint`** for row highlighting
- **`BuildKey(...)`**, **`SafeTrim(...)`**, **`SafeTrimEnd(...)`**, and **`Csv(...)`**
- nested helper types:
  - **`FilterMode`**
  - **`ProgressInfo`**
  - **`BalanceRow`**

The business logic in that form was intentionally preserved. It reads:
- **`LEDGER.CUR`** via `LedgerCurReader.ReadAll(...)`
- **`CHECK.INV`** via `CheckInvReader.ReadAll(...)`
- **`INVOICE.CHK`** via `InvoiceChkReader.ReadRecord(...)`

using paths from:
- **`LegacyDataPaths.LedgerCur`**
- **`LegacyDataPaths.CheckInv`**
- **`LegacyDataPaths.InvoiceChk`**

It then builds a composite customer/check key using `BuildKey(code, checkNum)`, indexes invoice mappings, resolves invoice amounts, caches invoice amounts in `amtCache`, and identifies two major categories of exceptions:
1. **No CHECK.INV mapping**
2. **Mapped checks whose invoice totals do not balance to the check amount**, including cases where invoice references exist but invoice records cannot be found

The tolerance rule stayed intact:
- **`Tolerance = 1D`**
which preserves the known DOS-era behavior that differences under one dollar are treated as acceptable.

The primary implementation work today was a styling and usability pass on `FormLedgerDoesntBalance` so it would look more like the rest of the DOS-inspired application rather than like a generic Windows utility form. The screen was changed to include:
- dark charcoal/black background
- black top header area
- upper-left large yellow **CHECKS** title
- upper-right yellow date/time clock
- silver toolbar buttons
- darker `DataGridView`
- `(ESC) Close` button and keyboard support
- DOS-like visual treatment overall

An explicit compile/debug issue came up when adding the clock: **`Timer`** was ambiguous because both `System.Windows.Forms` and `System.Threading` were imported. That was resolved by explicitly using:
- **`System.Windows.Forms.Timer`**

# 3. Key Technical Findings
- **`FormLedgerDoesntBalance.vb`** is already a substantial functional implementation, not just a UI shell.
- The core business logic is organized around:
  - `RunReportAsync()`
  - `ComputeRows(...)`
  - `ApplyFilterAndBind()`
  - `dgv_RowPrePaint`
- The form distinguishes between:
  - rows with **no CHECK.INV mapping**
  - rows with **invoice mappings whose totals do not match the check amount**
- `ComputeRows(...)` uses a cache:
  - `Dim amtCache As New Dictionary(Of Long, Decimal)()`
  to avoid repeatedly reading invoice records for duplicate invoice references.
- The composite relationship key is built using:
  - `BuildKey(code, checkNum) = trimmed customer code + "|" + trimmed check number`
- Missing `CHECK.INV` data causes rows to be flagged as:
  - `"No CHECK.INV mapping"`
- Missing invoice records in `INVOICE.CHK` cause rows to be flagged via note text:
  - `"Invoices not found in INVOICE.CHK"`
- The logic currently considers a row unbalanced when:
  - no mapped invoice amounts were found, or
  - `Math.Abs(delta) >= Tolerance`
- The DOS-era tolerance assumption remains baked into:
  - `Private Const Tolerance As Decimal = 1D`
- The initial one-line progress/status message was too wide for the command bar and got truncated.
- Splitting progress into two labels was a cleaner design:
  - status message on top
  - counts below
- The operator preferred the first split-label implementation visually.
- Ambiguous timer issue occurred because of:
  - `Imports System.Windows.Forms`
  - `Imports System.Threading`
  and both namespaces expose a `Timer`.
- Correct fix was to explicitly declare:
  - `Private ReadOnly tmrClock As System.Windows.Forms.Timer = New System.Windows.Forms.Timer()`
- `DataGridView` body text looked too heavy when styled bold; regular body font is visually preferable.
- Highlight colors had to be tuned in the context of the dark DOS-like theme; saturated gold/pink felt wrong.
- The final accepted visual treatment uses much lighter, softer pastel highlighting.
- Current title font in this form still uses an approximation and does not match the title font used on the Main Menu / Checks Menu.
- The app was successfully published and tested on the VM.
- The previous automated/incremental build-counter mechanism is missing after the crash/rebuild and needs restoration.

            @{ Expression = { Get-VersionNumber $_.Name }; Descending = $true },
            @{ Expression = { $_.LastWriteTime }; Descending = $true }

    $best = $ranked | Select-Object -First 1
    $bestNormalized = Get-NormalizedBaseName $best.Name
    $bestVersion = Get-VersionNumber $best.Name

    $group = $Files | Where-Object {
        (Get-NormalizedBaseName $_.Name) -eq $bestNormalized -and
        (Get-VersionNumber $_.Name) -eq $bestVersion
    }

    return $group
}

function Expand-ZipFile {
    param(
        [System.IO.FileInfo]$ZipFile,
        [string]$DestinationRoot
    )

    $extractFolderName = [System.IO.Path]::GetFileNameWithoutExtension($ZipFile.Name)
    $extractPath = Join-Path $DestinationRoot $extractFolderName

    if (Test-Path $extractPath) {
        Remove-Item -Path $extractPath -Recurse -Force -ErrorAction SilentlyContinue
    }

    New-Item -ItemType Directory -Path $extractPath -Force | Out-Null
    Expand-Archive -Path $ZipFile.FullName -DestinationPath $extractPath -Force

    return $extractPath
}

function Get-MainMarkdownCandidate {
    param(
        [System.IO.FileInfo[]]$MarkdownFiles,
        [string]$ExpectedBaseName
    )

    if (-not $MarkdownFiles -or $MarkdownFiles.Count -eq 0) {
        return $null
    }

    $expected = $ExpectedBaseName.ToLower()

    $ranked = $MarkdownFiles |
        Sort-Object `
            @{ Expression = {
                $name = $_.BaseName.ToLower()
                if ($name -eq $expected) { 100 }
                elseif ($name -like "$expected*") { 90 }
                elseif ($name -match 'checklist|readme|guide|instruction|instructions') { 10 }
                else { 50 }
            }; Descending = $true },
            @{ Expression = { $_.Length }; Descending = $true },
            @{ Expression = { $_.LastWriteTime }; Descending = $true }

    return $ranked | Select-Object -First 1
}

function Get-BestImportSourceFromGroup {
    param(
        [System.IO.FileInfo[]]$GroupFiles,
        [string]$TodayFolder
    )

    if (-not $GroupFiles -or $GroupFiles.Count -eq 0) {
        return $null
    }

    $zipFile = $GroupFiles |
        Where-Object { $_.Extension.ToLower() -eq ".zip" } |
        Sort-Object LastWriteTime -Descending |
        Select-Object -First 1

    if ($zipFile) {
        $extractRoot = Join-Path $TodayFolder "extracted"
        New-Item -ItemType Directory -Path $extractRoot -Force | Out-Null

        $extractPath = Expand-ZipFile -ZipFile $zipFile -DestinationRoot $extractRoot
        $expectedBaseName = Get-NormalizedBaseName $zipFile.Name

        $mdFiles = Get-ChildItem -Path $extractPath -Recurse -File -ErrorAction SilentlyContinue |
            Where-Object { $_.Extension.ToLower() -eq ".md" }

        $mdInside = Get-MainMarkdownCandidate -MarkdownFiles $mdFiles -ExpectedBaseName $expectedBaseName

        if ($mdInside) {
            return [PSCustomObject]@{
                SourceType    = "ExtractedMarkdown"
                ImportFile    = $mdInside
                ContainerFile = $zipFile
                ExtractPath   = $extractPath
            }
        }

        $jsonInside = Get-ChildItem -Path $extractPath -Recurse -File -ErrorAction SilentlyContinue |
            Where-Object { $_.Extension.ToLower() -eq ".json" } |
            Sort-Object `
                @{ Expression = { $_.Length }; Descending = $true },
                @{ Expression = { $_.LastWriteTime }; Descending = $true } |
            Select-Object -First 1

        if ($jsonInside) {
            return [PSCustomObject]@{
                SourceType    = "ExtractedJson"
                ImportFile    = $jsonInside
                ContainerFile = $zipFile
                ExtractPath   = $extractPath
            }
        }
    }

    $standaloneMdFiles = $GroupFiles |
        Where-Object { $_.Extension.ToLower() -eq ".md" }

    $expectedStandaloneBase = if ($GroupFiles.Count -gt 0) {
        Get-NormalizedBaseName $GroupFiles[0].Name
    } else {
        ""
    }

    $standaloneMd = Get-MainMarkdownCandidate -MarkdownFiles $standaloneMdFiles -ExpectedBaseName $expectedStandaloneBase

    if ($standaloneMd) {
        return [PSCustomObject]@{
            SourceType    = "StandaloneMarkdown"
            ImportFile    = $standaloneMd
            ContainerFile = $null
            ExtractPath   = $null
        }
    }

    $standaloneJson = $GroupFiles |
        Where-Object { $_.Extension.ToLower() -eq ".json" } |
        Sort-Object `
            @{ Expression = { $_.Length }; Descending = $true },
            @{ Expression = { $_.LastWriteTime }; Descending = $true } |
        Select-Object -First 1

    if ($standaloneJson) {
        return [PSCustomObject]@{
            SourceType    = "StandaloneJson"
            ImportFile    = $standaloneJson
            ContainerFile = $null
            ExtractPath   = $null
        }
    }

    return $null
}

function Get-LatestPreviousHistoryFile {

    $previousFolder = Get-ChildItem -Path $BasePath -Directory -ErrorAction SilentlyContinue |
        Where-Object { $_.Name -lt $Today } |
        Sort-Object Name -Descending |
        Select-Object -First 1

        return $null

    $previousFile = Get-ChildItem -Path $previousFolder.FullName -File -Filter "*_master-history.md" -ErrorAction SilentlyContinue |
        Sort-Object LastWriteTime -Descending |
        Select-Object -First 1

    return $previousFile
}
